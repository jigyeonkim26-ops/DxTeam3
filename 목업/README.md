# OVERLAP 기능별 목업

실제 앱 코드(`overlap/frontend`)와 분리된 정적 목업입니다.

- 시작 화면: `index.html`
- 상세 기능 목록: `MOCKUP_FEATURES.md`
- 디자인 검토: `../DESIGN_REVIEW.md`

## 지도 실행

`index.html`은 MapLibre GL JS CDN과 공개 지도 타일을 사용합니다. 로컬에서는 기존 목업 서버 주소인 `http://127.0.0.1:4173`으로 열면 됩니다.

일반 지도와 위성 지도 전환, 장소 마커, 검색, 사용자 요청 기반 GPS 이동을 확인할 수 있습니다.
