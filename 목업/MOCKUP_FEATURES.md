# OVERLAP 목업 기능 명세

## 화면별 구성

| 기능 | 화면 파일 | 목업에서 확인하는 내용 |
| --- | --- | --- |
| 지도·장소 탐색 | `index.html` | MapLibre 일반·위성 지도, GPS, 마커, 검색, 장소 하단 시트 |
| 장소 아카이브 | `features/place.html` | 장소별 기록 목록과 기록 상세 진입 |
| 피드 | `features/feed.html` | 현재 모임 기록의 최신순 누적 피드 |
| 기록 작성 | `features/compose.html` | 현장 카메라 촬영, 장소·모임·방문일·본문 입력 |
| 모임 | `features/groups.html` | 모임 목록과 초대 코드 참여 |
| 새 모임 생성 | `features/create-group.html` | 새 모임 생성, 초대 코드·카카오톡 공유 링크 생성 |
| 링크 초대 확인 | `features/join-group.html` | 초대 링크를 연 사용자의 참여 확인·완료 화면 |
| 알림 | `features/notifications.html` | 새 기록·댓글·모임 초대 알림함 |
| 알림 설정 | `features/notification-settings.html` | 유형별 알림, 장소 근처 리마인드, 방해 금지 시간 |

## 지도와 GPS

- 지도 렌더러는 오픈소스 `MapLibre GL JS`입니다.
- 기본 중심 좌표는 광주 CGI센터(광주 남구 송암로 60) `35.110662, 126.877554`입니다.
- `일반`은 OpenStreetMap 타일, `위성`은 Esri World Imagery 타일을 사용합니다.
- `내 위치` 버튼을 누른 순간에만 브라우저 GPS 권한을 요청합니다. 위치 추적은 지속하지 않습니다.
- GPS 권한 거부 또는 MapLibre CDN 접근 실패 시에도 목업용 지도·마커를 표시합니다.

## 목업 한계

- 공개 타일은 시연용입니다. 실제 서비스 배포 전에는 지도·위성 타일 제공자의 이용량·상업 이용·표시 의무 정책을 검토하고 적합한 제공자를 계약해야 합니다.
- 실제 서버, DB, 사진 업로드, 모임 가입, 카카오톡 공유 API는 연결하지 않았습니다.
- 방문 확인은 서버 검증과 위치 권한 정책이 정해질 때까지 비활성화했습니다.
