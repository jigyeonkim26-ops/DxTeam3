# Swarm 참고와 오버랩 첫 구현 범위

확인일: 2026-10-02. 공개된 Foursquare 공식 도움말을 참고했습니다. Swarm 앱을 직접 실행해 화면을 확인한 것은 아닙니다. 아래 내용은 기능 흐름을 참고한 오버랩 설계이며 Swarm과의 API 연동이나 소스 코드 복제가 아닙니다.

## 참고한 사실과 적용 방향

| 공식 안내의 Swarm 기능 | 오버랩 적용 방향 | 이번 코드 |
|---|---|---|
| 장소에 체크인하고 설명·사진·친구를 추가 | 장소를 고르고 글과 추억 날짜를 남기기 | 글과 날짜 구현, 사진·동행자 태그는 후속 |
| 지도에서 과거 체크인과 상세 내용 확인 | 모임 기록이 있는 장소를 지도 핀으로 표시 | 좌표·기록 수 등 API 구현, 지도 화면은 프론트 담당 |
| 장소 검색과 장소 상세 탐색 | 동일 장소 ID에 여러 기록 연결 | 모임에 수동 등록한 장소 검색, 외부 지도 검색은 후속 |
| 친구 관계와 체크인 공유 | 대학교 친구·동네 친구처럼 모임별 열람 | 초대 가입과 모임별 권한 구현 |
| 기록을 돌아보는 기능 | 같은 장소에서 각 사람이 다른 날짜에 남긴 기억 모아보기 | 날짜순 타임라인 구현 |

여기서 모임별 묶기와 여러 사람의 날짜별 기억을 함께 보는 경험은 오버랩이 강조할 방향입니다. 해당 기능이 Swarm에 전혀 없다는 뜻이나 독점적인 차별성 판단은 아닙니다.

## 첫 구현에서 둔 가정

- 기록 하나는 모임 하나와 장소 하나에 속합니다.
- 모든 기록은 해당 모임 회원에게 공개됩니다. 나만 보기·전체 공개는 아직 없습니다.
- 모임에 가입하면 그 모임의 과거 기록도 볼 수 있습니다.
- 장소도 모임 단위로 관리합니다. 서로 다른 모임에서 같은 카페를 등록해도 다른 장소 ID입니다. 한 모임 안에서는 기존 장소를 선택해 기록을 묶습니다.
- 본문은 최대 2,000자이며 사진 없이 글만 등록할 수 있습니다.
- 추억 날짜는 한국 시간 기준 오늘까지 입력합니다. 날짜만 저장하며 작성 시각은 별도 UTC 시각입니다.
- 작성자만 수정·삭제할 수 있습니다. 모임장에게 타인 기록 삭제 권한을 부여하지 않았습니다.
- 초대 코드를 알면 가입할 수 있습니다. 코드 조회는 모임장에게만 허용합니다.
- 탈퇴·회원 내보내기·계정 삭제·초대 만료·중복 요청 방지는 후속 설계 대상입니다.
- 서버가 재시작되면 데이터가 초기화됩니다. 로컬 개발에서 단일 프로세스로 실행합니다.

실제 사용자 데이터 도입 전에 팀이 이 규칙을 확인하고 변경하면 됩니다.

## 단계별 결과물

1. 현재: 인증과 권한이 적용된 글 기록 API, 장소별 모아보기와 지도용 API.
2. MySQL: 회원·모임·가입 관계·장소·기록을 영구 저장, 테이블 변경 이력 관리, 토큰 저장 방식 전환.
3. 사진·지도: 업로드 크기/형식 검사와 모임 권한이 적용된 사진 제공, 지도 검색 결과 연결.
4. 앱 연결: 안드로이드 화면에서 API 호출, 로딩·실패·토큰 만료 상태 처리.
5. 후속 후보: 동행자 태그, 댓글·반응, 과거 추억 알림, 모임 관리. 스티커·랭킹·코인은 핵심 기록 흐름 이후 팀에서 도입 여부를 결정.
