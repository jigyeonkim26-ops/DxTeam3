# 전달 전 검증 결과

검증일: 2026-10-02. 환경: Linux, Python 3.12.14.

- `python -m pytest -q`: **13개 테스트 통과**.
- Uvicorn을 별도 프로세스로 실행하고 HTTP 요청으로 `/health`, `/docs`, `/openapi.json` 응답 확인.
- OpenAPI 명세: 경로 14개, HTTP 작업 19개. 실행 확인용 API 포함.

검증 범위:

1. 인증 필요 여부, 비밀번호 Argon2id 저장, 대소문자 정규화 후 중복 아이디 차단, 로그아웃.
2. 만료된 로그인 토큰 거부, 입력 오류 응답에서 비밀번호 원문 제외.
3. 초대 가입, 중복 가입 방지, 모임장 전용 초대 조회.
4. 비회원의 모임·장소·기록·타임라인·지도 접근 및 작성 차단.
5. 같은 장소의 서로 다른 작성자·추억 날짜 정렬과 지도 집계.
6. 작성자만 수정·삭제, 삭제 후 지도 집계 반영.
7. 다른 모임의 장소·기록 ID를 사용하는 요청 차단.
8. 작성자 위조 필드·미래 날짜·빈 내용·좌표 범위 검사.
9. 검색, 날짜 필터, 페이지 구분, 잘못된 범위 및 중복 장소 검사.
10. 동시 기록 등록 시 ID 충돌 없이 저장.
11. 서버를 새로 만들면 임시 데이터와 로그인 상태가 초기화되는 동작.

테스트 중 Starlette의 httpx 호환 경로에 대한 사용 중단 예정 경고가 1건 표시됐습니다. 13개 테스트는 모두 통과했으며 일반 서버 실행은 정상 확인했습니다. 의존성 업데이트 때 테스트 클라이언트도 함께 검토할 수 있습니다.

사용자 컴퓨터의 Windows/macOS 환경에서는 직접 실행하지 않았습니다. 두 운영체제용 실행 명령은 README에 제공합니다. MySQL 연결, 실제 안드로이드 통신, 외부 지도 API, 사진 업로드, 공개 서버 배포는 이번 구현·검증 범위에 포함되지 않습니다.
